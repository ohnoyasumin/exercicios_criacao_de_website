TÓPICO 05

Princípios do Contraste Visual e Escala Tipográfica

Publicado por Silvio • Atualizado para Web Design

A hierarquia tipográfica é a estrutura invisível que orienta os olhos do leitor através de uma interface web. Sem uma diferenciação clara entre títulos, subtítulos e texto de corpo, o usuário enfrenta uma carga cognitiva elevada para compreender a relevância das informações.

1. A Escolha das Famílias Tipográficas

Para construir um contraste harmônico, utilizamos uma combinação de duas fontes distintas:

  • Montserrat (Sans-serif): Utilizada nos títulos e rótulos devido ao seu apelo geométrico e alta legibilidade em blocos destacados.
  • Merriweather (Serif): Aplicada no corpo de texto para proporcionar um fluxo confortável de leitura em parágrafos longos.

2. A Escala Modular (Major Third - 1.25)

Em vez de escolher tamanhos de fonte aleatórios, uma escala tipográfica modular garante uma relação matemática proporcional entre cada nível de texto:

Elemento Escala (rem) Pixels (Base 16px) Aplicação
h1.main-title 2.441 rem ~39 px Título principal da página
h2 1.953 rem ~31 px Seções primárias
h3 1.563 rem ~25 px Subseções de artigos
body / p 1.000 rem 16 px Texto corrido
.tagline / .meta 0.800 rem 12.8 px Avisos e meta-informações

3. Ajuste Dinâmico com JavaScript

Com a manipulação do DOM em JavaScript, é possível alterar a hierarquia visual em tempo real para responder a preferências de acessibilidade do usuário ou criar temas com diferentes densidades de conteúdo.
